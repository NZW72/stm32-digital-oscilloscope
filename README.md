# STM32 简易数字示波器

2026 年陕西电子设计竞赛 G 题项目源码整理。基于 STM32F407VG、CMSIS-DSP 与串口屏，实现信号采集、时域波形和频谱显示。

## 项目功能

- ADC 采集与 1024 点 FFT。
- 峰峰值、有效值、频率测量。
- 基波与二次谐波幅值分析。
- 去直流、Hann 窗、中位数滤波及过零检测辅助测频。
- 串口屏波形与频谱显示、波形冻结和刷新交互。

## 我的工作

电路主体结构设计、全部软件端开发、算法设计、串口屏调试，以及整体协调。

## 工程结构

| 路径 | 内容 |
| --- | --- |
| `Project.uvprojx` | Keil µVision 工程入口 |
| `User/main.c` | 采样、测量、显示和交互主流程 |
| `System/` | FFT、采样及信号处理等模块 |
| `Hardware/` | 串口屏通信、事件与硬件驱动 |
| `Start/`、`Library/` | 启动文件与 STM32 外设库 |
| `CMSIS-DSP/` | 数字信号处理依赖 |
| `SOURCE_MANIFEST.json` | 整理时原始文件的 SHA-256 清单 |

## 打开与编译

1. 安装 Keil MDK 与 STM32F4 器件支持包。
2. 打开 `Project.uvprojx`。原工程配置为 STM32F407VG、ARM Compiler 6.23、Keil.STM32F4xx_DFP 1.0.8。
3. 核对本地编译器及器件包配置后构建；连接硬件前核对引脚、电平、时钟和串口屏对象名称。

串口屏字段可从 `User/main.c` 的 `HMI_OBJ_*` 和屏幕命令查阅。当前整理包未包含电路原理图、PCB 文件和串口屏 HMI 设计源文件，无法仅凭此仓库复刻完整硬件。
